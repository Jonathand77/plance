Generar links de pago

Este flujo te permite crear un link de cobro para compartirlo por canales externos como correo, WhatsApp, SMS o redes sociales, sin necesidad de integrar un checkout completo en tu sitio.

Es una opción muy útil para ventas asistidas, cobros remotos, recaudo rápido y escenarios donde el comprador completa el pago desde un enlace seguro.

¿Cuándo usar Links de Pago?

  • Cuando necesitas cobrar sin desarrollar una experiencia de checkout propia.
  • Cuando operas ventas por canales conversacionales o externos.
  • Cuando quieres acelerar habilitación comercial con bajo esfuerzo técnico.

Qué podrás validar en esta vista

  • Generación del request para crear el link.
  • Parámetros principales del cobro y su consistencia.
  • Respuesta esperada del servicio y su interpretación funcional.

Flujo resumido

  1. Configuras los datos del cobro.
  2. Generas el link desde el servicio.
  3. Compartes el enlace con el cliente.
  4. Monitoreas el resultado de la transacción.
